Anthropic 的类比：一支轮班的工程队伍，每位新工程师到岗时对上一班毫无记忆。上下文窗口装不下的项目，必须有"外部记忆"承载进度。

初始化班把需求拆成 200+ 条可验证条目，初始全部"未通过"——完工标准先于开工写死

进度日志 claude-progress.txt

每班收工写下：做了什么、败在哪、下一步从哪继续

提交历史 git history

外部记忆：任何时刻可回滚到最近可用状态，坏改动可撤销

跨会话笔记 NOTES.md / MEMORY.md

长期状态与偏好沉淀，团队知识不随会话消失

失败模式预置（初始化班一次做好）每班纪律（执行班照章执行）

出处：Anthropic《Effective Harnesses for Long-running Agents》（2025-11）。四个记忆文件对应四个管理机制：功能清单=验收标准前置、进度日志=交接班记录、git=可回滚的存证、笔记=知识资产。右下表格是最有说服力的部分——每种失败模式都有对应的制度设计，这就是"驾驭工程"的含义：不指望 AI 自觉，靠环境设计让它没办法犯这类错。
