结论三 / 成本与治理

57% 的预算给了 13.5% 的请求；科技新披露的 Bedrock 账单再添证据：top2 海外模型占 60%、国产仅 6.8%；塞防仍 0 可见。

  • 成本信息存疑：从网关带回的成本是 API 价格，如果签约了不同套餐，价格会有显著影响
  • 单价差 24 倍：Opus $1.003/百万 token vs DeepSeek $0.041，后者承载了 55% 请求
  • 科技 Bedrock（新增披露）：62 天 $18.9 万、10 个模型、133 万次请求，gpt-5.6-sol + Mistral 占 60%，国产模型仅 6.8%（同集团航空已达 65%）
  • Bedrock 小模型（gpt-oss / Gemma / Ministral）合计 $2.77 万、占 15%，单价低但用量存疑，需核对调用量
  • Gemini 性价比最差：$1.602/百万 token，缓存命中率仅 38.5%（全网关均值 88%）
  • Cursor 13 人花 $1.94 万，人均 $1,495/两月，是 Claude Code 人均（$896）的 1.7 倍
  • 无主 key：25 个"未标注用途" key 成功率仅 52.3%；未匹配部门花费 $1.27 万（4.8%）无法归因
