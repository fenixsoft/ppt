# DS480 驾驶舱原型 · 风格约束（STYLE-GUIDE）

> 本文件是 5 张驾驶舱页面统一的**唯一风格来源**。任何页面（含后续新增）必须引用本规范的
> token 与组件，不得自定颜色 / 字号 / 间距。修改风格只改这里 + `index.html` 的 `:root`。

## 1. 设计定位

- **场景**：汇报投屏演示。画布固定 **1920×1080**，JS `scale-to-fit` 适配任意投影分辨率。
- **气质**：浅色企业管理系统风（Ant Design 中性体系 + 克制用色），品牌绿取自 Excel 原稿
  绿色表头的文档基因，同时呼应充电/新能源行业语义。
- **信息密度**：远距可读。正文 ≥ 13px，KPI 数值 40px+，禁止小字堆砌。

## 3. 字号阶梯（投影可读下限）

| 角色 | 规格 |
|---|---|
| 顶栏页标题 | 22px / 600 / 白 |
| 顶栏 tab | 15px / 500 |
| 章节标题 | 17px / 600，配「一/二/三…」编号签 + 4px 绿色左轨 |
| KPI 数值 | 40–44px / 600，proportional figures（表格内才用 `tabular-nums`）|
| 正文 / 表格 | 13–14px；轴标签、脚注 12px |

## 4. 布局与组件

- **顶栏**：64px `--brand-900` 通栏。左＝页标题 + 项目副标；右＝5 个驾驶舱 tab
  （active：白底绿字胶囊；未建：半透明禁用态）。键盘 ←/→ 与数字键 1-5 切页。
- **内容网格**：12 列，间距 14–16px，页边距 24px。章节按 Excel 原稿「一/二/三/四/五」顺序编号排列。
- **卡片**：白底、1px `--border`、圆角 8px、无阴影（投屏不发灰）。
- **章节头**：左侧 4px `--brand-700` 竖轨 + 编号章（一、二…）+ 标题 + 右侧 muted 补充说明。
- **KPI tile**：label（13px muted）→ value（40px+）→ sub（目标/实际/达成率，12px muted）。
- **表格**：两级表头（目标组 / 实际 / 监控组），表头底 `#fafafa`，数字右对齐 `tabular-nums`，
  整行全空的行用 `--text-3` 弱化，单元格空值统一 `—`。
- **状态灯**：12px 圆点 + 文字标签（绿=正常 `#0ca30c` / 黄=风险 `#fab219` / 红=延误 `#d03b3b`），
  **永远 icon+文字，不许只靠颜色**。
- **XX 待定徽章** `.xx`：`#fffbe6` 底 / `#ffe58f` 边 / `#874d00` 字，圆角 4px，表示原稿待确认字段。
- **GO WITH RISK 类决策徽章**：amber 徽章（同 XX 配色）+ ▲ 图标。

## 5. 图表规范（ECharts 5，本地 `echarts.min.js`）

- **形式选择**：单指标趋势/对比→单色柱；盈亏→±发散柱（负红正绿）；比率→中性墨色折线；
  多实体对比→分类色。**禁双 Y 轴**；不同量纲拆成小图（small multiples）。
- **柱**：宽 ≤24px，数据端 4px 圆角、基线端直角；相邻柱留白由 band gap 提供。
- **折线**：2px 圆角连接；端点符号 ≥8px、白色 2px 描边环。
- **网格/轴**：1px 实线 `#eef0f2`，never 虚线；轴线/刻度线隐藏；轴文字 12px `--text-3`。
- **数值标签**：直接标在柱顶/点旁（13px，`--text-1`，千分位），文字**不**用系列色；
  每图合计写进卡片头右侧 muted 文本，不占图表位。
- **图例**：单系列不配图例（标题即说明）；≥2 系列必须配图例。
- **tooltip**：白底、1px 边、12–13px，axis-shadow 指示。
- 主题统一在 `index.html` 的 `baseChartTheme()`，新图必须复用。

## 6. 数据保真规则

1. 只呈现 Excel 截图中的信息，不虚构数值；完全为空的**列**（如"核算逻辑"）可合并/省略，
   完全为空的**行**保留（指标体系本身是信息），值用 `—`。
2. `XX` 类占位 → `.xx` 徽章原样保留，页面右下角固定脚注说明。
3. 千分位分隔；金额单位标在行/列名（万元、人月、%）；年份 4 位。
4. 原截图水印（人名/工号）一律不带。
5. 「实际」列数据缺失时整列 `—`，达成率/差异额同；不做任何推算。

2. 章节编号沿用 Excel 原稿序号；图表用 `baseChartTheme()` + 系列色 token。
