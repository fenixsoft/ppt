管理驾驶舱 2.0：架构增量

架构增量一：从局部来看，新增 Agent 层，指标体系的重要性进一步增加

★ Agent 应用层（新增）ChatBI 智能问数 · 异动归因引擎 · 报告生成/处置 Agent
指标体系地位跃升：成为 LLM 防幻觉的"事实锚点"。所有口径的唯一出处
存储与计算数据 API · 数据湖 · 权限（不变） · 新增向量库（存非结构化知识）
业务系统产生数据的源头，基本不变

将新增的 Agent 理解为管理者的“数字分身”

管理者的关注点在随着企业规模、产品阶段、技术发展而变化，决策逻辑也不是恒定的，让 AI 学习管理者，模拟决策过程，拟合决策结果是 IOC 应用发展的趋势。下一代 RSI 的 AI 应用针对这点进行了增强


指标体系是约束模型的关键

大模型不能直接吃明细数据，表结构理解错一点，答案就错，这就是"一问就胡说"的来源。它必须吃口径可信的指标：指标定义统一、含义明确、出处唯一。


架构增量二：从整体来看，完全符合 AI 工厂生产智能的"输入源 - 产出物"结构

输入源 ① 指标体系 → 可信事实

口径校准的经营数字与含义，AI 一切判断的事实基础。

输入源 ② 本体 + 案例库 → 知识经验

设备/订单/工序的关系规则，加上历史诊断处置案例。

输入源 ③ 模型算力 → 认知与推理

综合、归因、生成能力。算力只是成本项，买的是认知。

▼
输出 = 结论 + 证据链 + 备选方案　→　决策
这就是智能的具象化，结论必须可追溯：结论 → 指标 → 明细 → 凭证
